# LTHD Student AI Guide

A student guide to AI use in Leadership, Technology, and Human Development (LTHD) courses at Georgia Southern University. Students read nine short sections, answer an eight-question quiz, sign an acknowledgment, and download a completion certificate (PDF) to upload in each course.

- `index.html` is the whole site: one self-contained page, with no build step and no data stored or sent anywhere.
- Content source and decisions: kept by the LTHD chair (guide version 2026-11).
